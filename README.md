# 🍞 Roti Li Doku

A premium, modern artisan bakery landing page featuring a high-end "scrollytelling" experience. 

Designed with a handcrafted aesthetic and cinematic scroll-linked video animations to showcase the freshness, craftsmanship, and premium quality of Roti Li Doku's baked goods.

## 🌟 Live Demo

**[View the Live Website](https://manansaipi.github.io/roti-li-doku/)**

## ✨ Features

- **Scrollytelling Hero:** High-performance HTML5 Canvas image sequence that plays as the user scrolls.
- **Smooth Scrolling:** Implemented using Lenis for buttery smooth navigation.
- **Dynamic Animations:** Scroll-triggered text and element animations powered by Framer Motion.
- **Bento Box Gallery:** A beautiful CSS Grid gallery showcasing the bakery's best products.
- **Fully Responsive:** Perfectly optimized for both desktop and mobile viewing.

## 🛠️ Tech Stack

- **Framework:** React + Vite
- **Styling:** Tailwind CSS
- **Animation:** Framer Motion
- **Scroll Handling:** Lenis Scroll
- **Rendering:** HTML5 Canvas (for 60fps video scroll)

## 🚀 Getting Started

To run this project locally:

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## 📦 Deployment

This project is configured to automatically deploy to GitHub Pages. To publish a new version:

1. Commit your changes to the `main` branch.
2. Run the deployment script:
   ```bash
   npm run deploy
   ```
